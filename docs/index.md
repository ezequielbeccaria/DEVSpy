# DEVSpy Documentation

DEVSpy is a small, headless Python 3 engine for simulating discrete-event systems written in [DEVS](https://en.wikipedia.org/wiki/DEVS) (Discrete Event System Specification) form.

## Table of contents

- [Getting started](getting-started.md) — install, hello-world atomic, hello-world coupled, run the examples.
- [DEVS concepts](concepts.md) — quick primer on atomic vs coupled models, `phase`/`sigma`, the transition functions.
- [API reference](api-reference.md) — every public class and method with signatures.
- [Examples](examples.md) — walk-throughs of every script in `examples/`.
- [Contributing](contributing.md) — development setup with Poetry, tests, and code style.
